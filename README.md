# Baseline public documentation

This repository contains a **proposed privacy policy**, not an effective privacy notice.

- [Read the proposal](privacy.md).
- [View the website](index.html).

The proposal describes intended commitments for a personal health-history dashboard. Publishing it does not activate or verify those commitments. Before adoption, operator contact information, relevant service locations, and implementation verification are required. Do not submit this proposal as an active privacy notice.

Only public documentation belongs in this repository. It contains no application source, health records, credentials, private service addresses, or internal audit material. Do not post health data, account credentials, or privacy requests in public GitHub discussions or issues.

`privacy.md` is the readable source; `index.html` is its static website rendering. The page loads no scripts, remote fonts, trackers, or external assets. GitHub Pages may log visitor IP addresses for security under its own privacy practices.
